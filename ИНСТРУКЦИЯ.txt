PDF PRINT ROUTER — печать многоформатных PDF на разных принтерах
=================================================================

ЧТО ЭТО
Приложение для Windows с просмотрщиком PDF. Один многостраничный
документ со страницами разных форматов (A4, A3, A2/A1 для плоттера,
этикетки) можно разложить на задания и распечатать: каждый формат —
на своём принтере, со своими настройками (ориентация, дуплекс, копии,
масштаб, поля, цвет).

ТРЕБОВАНИЯ
1. Windows 10/11
2. SumatraPDF 3.2+ — https://www.sumatrapdfreader.org/download-free-pdf-viewer
   (через него идёт печать: тихая, с точными настройками)
   Python ставить вручную НЕ нужно — build.bat сделает это сам.

ЗАПУСК
Вариант А (готовый exe — рекомендуется): двойной клик по build.bat.
Скрипт сам скачает и установит Python (без прав администратора),
поставит зависимости и соберёт приложение. Через 5-10 минут готовое
приложение будет здесь:
    dist\PDFPrintRouter\PDFPrintRouter.exe
Эту папку можно перенести куда угодно — Python больше не нужен.

Вариант Б (запуск из исходников): двойной клик по run.bat
(нужен уже установленный Python 3.10+).

КАК ПОЛЬЗОВАТЬСЯ
1. «Открыть PDF…» — выберите документ. Слева появятся миниатюры
   страниц с определённым форматом (например, "1 · A4 (книжная)").
2. «Авторазбивка по форматам» — страницы сгруппируются по размеру
   бумаги в готовые задания.
3. «Привязка принтеров…» — укажите один раз: A4 → офисный принтер,
   A3 → второй принтер, A1/A2 → плоттер. Привязка сохраняется
   и используется при каждой авторазбивке.
4. Для ручного задания: выделите страницы слева (Ctrl/Shift),
   нажмите «← выбранные», задайте принтер и настройки справа,
   «Создать задание».
5. «Печать всех заданий» — отправляет все задания разом (кнопка есть
   и на панели инструментов, и под списком заданий); «Печать
   выбранного» — только одно задание. Каждое задание сначала
   собирается в PDF точно под формат бумаги (масштабирование,
   поворот, центрирование, поля), затем уходит на свой принтер.

ОСОБЕННОСТИ
- Два языка интерфейса: русский и английский. Переключение — справа
  на панели инструментов («Язык:»), работает на лету, без перезапуска;
  выбор сохраняется в настройках.
- Панель задания оформлена как диалог печати Foxit Reader: слева
  просмотр размещения — сама страница PDF на листе (масштаб, размеры
  документа и бумаги, листание страниц ‹ ›), справа — все настройки.
- Автоповорот: альбомные страницы поворачиваются на 90° и занимают
  весь книжный лист (бумага всегда подаётся книжно, как требуют
  драйверы). Снимите галочку, чтобы вписывать их без поворота.
- Ориентация «Альбомная» — для плоттера с рулоном: лист собирается
  длинной стороной ПОПЕРЁК рулона (например, A3 = 420 мм поперёк
  рулона 600 мм и 297 мм вдоль), а печать идёт напрямую через Windows
  (GDI) с точным размером бумаги — поэтому не зависит от того,
  что выбрано в умолчаниях драйвера. Для офисных принтеров
  (бумага из лотка) оставляйте «Авто»/«Книжная».
- Автоцентрирование: содержимое центрируется на листе. Снимите
  галочку, чтобы прижать его к левому верхнему углу с учётом полей.
- Дуплекс: при нечётном числе страниц добавляется пустая страница,
  чтобы копии не съезжали на один лист. Это нормально.
- Масштаб: «Вписать», «Заполнить», «100%» или «Свой процент» —
  рядом появляется поле для ввода процентов (например, 50% или 150%);
  страница масштабируется и центрируется на выбранном формате.
- «Свойства…» рядом с выбором принтера открывает диалог свойств
  драйвера принтера (как в Foxit Reader). Если нажать там OK,
  выбранные формат бумаги, ориентация, копии, дуплекс и цвет
  подставятся в задание, а сами настройки сохранятся как ваши
  личные умолчания — при следующем открытии диалог покажет их,
  а не заводские. Формат и ориентация при печати всё равно
  берутся из задания (поля «Бумага» и «Ориентация»).
- «Формат из принтера…» показывает все форматы бумаги, которые
  поддерживает драйвер выбранного принтера (для плоттера HP T520,
  например, A1/A2 и пользовательские формы), и добавляет выбранный
  в список «Бумага».
- «Свои форматы…» — редактор произвольных форматов (плоттеры, рулоны,
  этикетки). Они сохраняются в настройках, участвуют в авторазбивке,
  привязке принтеров и передаются в драйвер точным размером.
- Нестандартные форматы (этикетки 100×150 мм и т.п.): размер теперь
  передаётся принтеру напрямую. Если драйвер подставляет свой формат,
  создайте форму бумаги один раз в Windows — Панель управления →
  Устройства и принтеры → выбрать принтер → Свойства сервера печати →
  «Создать новую форму» — приложение подхватит её по размеру
  автоматически (например, «A3 поперёк» 420×297 мм для плоттера).
- Печать на плоттере HP T520: выберите ориентацию «Альбомная» —
  тогда A3/A2 лягут длинной стороной поперёк рулона 600 мм.
  Проверено на драйвере: страница формируется именно 420×297 мм
  (420 поперёк рулона). Если текст на выходе окажется «вверх
  ногами» — скажите, добавим разворот на 180°.
- «Экспорт заданий…» сохраняет готовые PDF и print_manifest.json —
  их можно печатать отдельно утилитой print_windows.py.

НАСТРОЙКИ хранятся в %APPDATA%\PDFPrintRouter\settings.json
(путь к SumatraPDF, привязка принтеров, пользовательские форматы,
язык интерфейса, последняя папка).

ЕСЛИ НЕ ПЕЧАТАЕТ
- Проверьте, что SumatraPDF установлен (или укажите путь к нему
  при первом запуске печати).
- Имя принтера должно совпадать с именем в Windows точно.
- Проверьте в настройках принтера, что не включено дополнительное
  масштабирование — страницы уже собраны под нужный формат.
