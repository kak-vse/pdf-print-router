# ЗАДАЧА: PDF Print Router — сборка exe и доводка печати

Этот файл — бриф для локального агента (Kimi Work). Проект создан в облачном
чате Kimi, код готов и протестирован; осталось собрать exe под Windows
и проверить реальную печать на принтерах пользователя.

## Что это за проект

Windows-приложение с GUI (PySide6) для печати многоформатных PDF:
один документ со страницами разных размеров (A4, A3, A2/A1, этикетки)
раскладывается на задания, каждое печатается на своём принтере со своими
настройками (ориентация, дуплекс, копии, масштаб, поля, цвет).

Структура:
- `main.py` — точка входа
- `app/pdf_document.py` — загрузка PDF, определение формата страниц (PyMuPDF)
- `app/jobs.py` — задания, авторазбивка по форматам, сборка PDF под бумагу (pypdf)
- `app/printers.py` — список принтеров Windows, печать через SumatraPDF CLI
- `app/settings.py` — настройки в %APPDATA%\PDFPrintRouter\settings.json
- `app/main_window.py` — интерфейс (русский)
- `build.bat` — автоустановка Python + зависимостей + сборка exe (PyInstaller)
- `run.bat` — запуск из исходников
- `tests/smoke_test.py` — headless-тест (QT_QPA_PLATFORM=offscreen)

## Что уже проверено (в облачной песочнице Linux)

- Ядро: определение форматов A4/A3/A1/100×150 мм, авторазбивка, масштабирование
  страниц под бумагу, добивка пустой страницы для дуплекса — всё работает.
- GUI: headless smoke-тест проходит полностью (см. tests/smoke_test.py).
- Сборка PyInstaller (тестировалась на Linux) — проходит, бинарник запускается.

## Что нужно сделать локально (Windows)

1. Убедиться, что установлен SumatraPDF 3.2+
   (https://www.sumatrapdfreader.org/download-free-pdf-viewer). Если нет —
   скачать и установить.
2. Запустить `build.bat`. Он сам поставит Python (если нет) и зависимости,
   соберёт `dist\PDFPrintRouter\PDFPrintRouter.exe`. Если на каком-то шаге
   ошибка — разобраться и исправить (скорее всего: антивирус блокирует
   PyInstaller, либо нет интернета для pip).
3. Запустить приложение (exe или run.bat), открыть любой тестовый PDF,
   нажать «Авторазбивка по форматам».
4. Проверить список принтеров: приложение должно увидеть принтеры Windows
   (win32print, запасной вариант — PowerShell Get-Printer). Если список
   пуст — отладить app/printers.py.
5. В «Привязка принтеров…» назначить форматы на реальные принтеры
   пользователя (A4 → офисный, A3 → второй, A1/A2 → плоттер).
6. Сделать пробную печать ОДНОЙ страницы на каждый принтер (кнопка
   «Печать выбранного»). Проверить: правильный принтер, формат, ориентация.
7. Если драйвер игнорирует настройки (копии/дуплекс/формат) — сообщить
   пользователю и скорректировать app/printers.py (например, добавить
   явный выбор лотка или формы бумаги).

## Известные нюансы

- Нестандартные форматы (этикетки 100×150 мм): форму бумаги нужно один раз
  создать в Windows (Панель управления → Устройства и принтеры → Свойства
  сервера печати → Создать новую форму), иначе драйвер подставит свой формат.
- Дуплекс: при нечётном числе страниц в задании добавляется пустая страница —
  это специально, чтобы копии не съезжали на один лист.
- Печать идёт через SumatraPDF CLI: -print-to, -print-settings
  (paper=,fit,portrait/landscape,simplex/duplex/duplexshort,copies=N,color/monochrome).
- Настройки (путь к SumatraPDF, привязка принтеров) хранятся в
  %APPDATA%\PDFPrintRouter\settings.json.

## Критерий готовности

PDFPrintRouter.exe собран, запускается, видит принтеры пользователя;
пробная страница каждого формата напечатана на правильном принтере
с правильными настройками.
